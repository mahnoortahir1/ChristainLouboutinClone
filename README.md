# Christian Louboutin Website Clone

A responsive e-commerce web clone replicating the design, aesthetic, and layout of the official Christian Louboutin website.

## Features

- **Hero & Landing Page**: Modern visual showcases and brand styling.
- **Collections Showcase**: Dedicated pages for Men's and Women's collections, as well as seasonal collections.
- **Interactive Navigation**: Slide-out menus, search functionality, and product category navigation.
- **Shopping Flow**: Wishlist, cart, and authentication/login pages.
- **Responsive Layout**: Designed for seamless viewing across screen sizes.

## Built With

- **HTML5** - Semantic page structuring
- **CSS3** - Layouts, animations, and custom typography
- **JavaScript (ES6+)** - Dynamic UI interactions and navigation controls
